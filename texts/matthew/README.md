# Matthew — Source and Licensing Record

## ECB source
- Book: Gospel of Matthew
- Base dialect: Sahidic Coptic
- Digital source: Coptic SCRIPTORIUM, corpus `sahidica.nt`
- Document URN for chapter 1: `urn:cts:copticLit:nt.matt.sahidica:1`
- Source title: **Sahidica - A New Edition of the New Testament in Sahidic Coptic**
- Copyright: **Copyright (c)2000-2006 by J Warren Wells. All rights reserved.**

The Sahidica licensing information permits the text to be used in free electronic New Testament editions when the full source title and copyright information are included and credited. Print publication requires separate written permission.

## ECB status
Matthew 1 is being entered as an ECB Arabic working translation directly against the Sahidic base. It is not copied from an existing Arabic Bible translation.

Current batch:
- Matthew 1:1–7
- status: draft v0.1
- alignment: verse-level first; word-level alignment follows linguistic review

## Editorial note
Matthew 1:7 in the Sahidic display contains ⲁⲥⲁⲫ. ECB keeps the corresponding name as **آساف** in the draft rather than silently normalizing it to a familiar Arabic reading. This will be reviewed in the textual apparatus.
