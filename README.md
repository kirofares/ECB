# ECB — The Egyptian Coptic Bible

**ECB** is an independent project for **The Egyptian Coptic Bible – Arabic Translation**.

The project is designed to present the Coptic biblical text alongside a careful Arabic translation, with textual and linguistic notes kept separate from the translated text.

## Project structure

- `index.html` — public landing page and reader prototype.
- `data/books.json` — initial structured book index.
- `docs/translation-methodology.md` — editorial and translation methodology.
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment.

## Editorial status

The website structure is live first. Full biblical text will only be added after the Coptic source edition/witnesses and publication rights are documented.

## Planned reader

The target reader structure is:

`Testament → Book → Chapter → Verse`

Each verse can support:

- Coptic source text
- Arabic translation
- literal gloss
- linguistic notes
- textual variants
- revision history
