# ECB Translation Methodology

## 1. Establish the Coptic source
Each translated passage must identify the Coptic edition or textual witness used. Material variants should be recorded rather than silently normalized.

## 2. Linguistic analysis
Before producing idiomatic Arabic, analyze vocabulary, syntax, verbal forms, particles, names, and expressions in the Coptic text.

## 3. Arabic rendering
The Arabic text should be accurate and readable. It should avoid unnecessary interpretation and preserve meaningful textual features whenever Arabic allows.

## 4. Separate translation from commentary
The translated biblical text, literal glosses, explanatory notes, and textual-critical notes should be stored and displayed separately.

## 5. Controlled terminology
Maintain a glossary for recurring theological, historical, liturgical, and linguistic terms. Changes to established terms should be documented.

## 6. Uncertainty and variants
Uncertain readings, damaged text, ambiguous constructions, and significant variant readings should be explicitly marked.

## 7. Revision history
Material translation changes should be traceable through version history and accompanied by a short editorial reason.
