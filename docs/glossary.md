## Arabic editorial preferences

- use **جباة الضرائب** in the main modern Arabic text; mention **العشارون** in explanatory notes when useful.
- use **ابن الإنسان** consistently.
- use **الروح النجس** when the Coptic wording refers to an unclean spirit; do not automatically replace it with **شيطان**.
- retain **الرب** for ⲡϫⲟⲉⲓⲥ and **الله** for ⲛⲟⲩⲧⲉ unless syntax or an embedded quotation requires a documented exception.
- avoid importing familiar Arabic Bible wording merely because it is traditional.
